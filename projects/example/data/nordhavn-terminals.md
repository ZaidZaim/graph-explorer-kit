# Nordhavn Terminals — Operations Note

Nordhavn Terminals operates container terminals in Aarhus, Denmark and Rotterdam,
Netherlands. Both Meridian Robotics and Kestrel Automation count Nordhavn as a
partner, which is why questions about the sector are hard to answer from any
single document. Status: confirmed.

## People

Lars Andersen is the Chief Operating Officer. He signed off on the Atlas pilot in
Aarhus and the Harbourmaster rollout in Rotterdam. Status: confirmed.

Mette Sørensen is Head of Automation. Status: confirmed.

## Deployments

The Aarhus terminal runs Atlas Yard Mover units scheduled by Harbourmaster. This is
the only site where both vendors' systems run together. Status: confirmed.

The Rotterdam terminal runs Harbourmaster against third-party equipment.
Status: confirmed.
